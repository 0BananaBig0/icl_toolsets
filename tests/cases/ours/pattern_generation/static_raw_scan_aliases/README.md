# Static serial aliases and inversion

Self-constructed IEEE1687 6.3 scan_signal/6.5 alias/7.9.12 fixture. SI and the
inter-register bridge invert; the SO alias also inverts. Ascending a and mirror
indices check declaration ordering. Physical SI10110 loads a01/b110. Physical
SI01001 loads a10/b001. Explicit SO expectations are physical serial data, never
hardware assumptions. Vendor qualification is recorded separately.

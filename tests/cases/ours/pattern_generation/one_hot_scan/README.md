# One-hot scan execution fixtures

Self-constructed complete designs exercising IEEE 1687-2014 §6.4.14 (printed
pp. 127–128). These are not copied vendor outputs or Tessent-certified patterns.
`network.icl` has nested one-hot returns, a zero-hot inactive subgroup and an
always accessible selector after the return group. The regression also derives
inverted, contending, unknown-enable and reserved-selector variants.

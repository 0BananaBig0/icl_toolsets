# Gated SIB root scans

A scalar root SIB selects an8-bit child whose local SelectPort follows the held
SIB update bit. Closed route1bit, open route9bits. Opening and closing use the
pre-update selection; bypassed child storage must have no effective events.

The stable source fixture remains a semantic test. Genuine Tessent2026.2 accepts
it but drops the stable flag and adds a comparison of open in its export; the
strict forward certificate is therefore rejected. Its reverse certificate passes.
The separate roundtrip source uses no stable flag and explicitly compares open
alongside the retained child value, so both tools receive the same observation
contract. All original failing evidence is retained; certificate policy unchanged.

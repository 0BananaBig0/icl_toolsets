# warptap — ranaumarnadeem/warptap

Three files from `tests/fixtures/golden_icl/`, taken at HEAD.

Found through a route the earlier rounds missed. The upstream README lists
two contributors, and the second — `ranaumarnadeem` — has 33 repositories.
Most are unrelated (an MBIST generator, a RISC-V core, assorted course work),
but two are DFT tools, and this one ships ICL as **golden fixtures**: inputs
whose expected output is checked, which is the closest thing to a third-party
formatter test found anywhere so far.

They matter here for a reason beyond being three more files. They are
*hand-written for a purpose*, not generated by a tool and not transcribed
from a standard — the two kinds this corpus already had. In particular they
carry comments that say what ICL cannot express:

    // warptap: fixed stub capture_value=0x2 -- no real CaptureSource;
    // ICL has no confirmed mechanism for a constant capture source, so
    // none is fabricated here (see module docstring).

That is a judgment about the language recorded in the file, from someone
writing ICL to be read by a tool. `flat_read_write.icl` and `nested_sib.icl`
each have several such notes.

`scan_mux.icl` adds nothing new syntactically — its three `ScanMux` blocks
use forms already covered — but it is the only file here exercising
`SelectedBy` on a bit-range (`SelectedBy SELREG[1:0]`).

All three pass, idempotent and character-preserving.
